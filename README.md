# POLYD

Сайт производителя установок приготовления и дозирования реагентов POLYD PLA и POLYD TWIN.

## Запуск и сборка

Требуется Node.js 24. Дополнительные пакеты для сборки не нужны.

```sh
node scripts/build.mjs
node scripts/check.mjs
node scripts/serve.mjs
```

Локальный просмотр: http://127.0.0.1:4173/. Комплект для обычного хостинга создаётся в public/.

## Демонстрация на GitHub Pages

Публикация выполняется автоматически из main через .github/workflows/pages.yml.

```sh
node scripts/build-pages.mjs
node scripts/check-pages.mjs
```

Отдельная сборка .pages-dist/ предназначена для адреса https://dymuravjev.github.io/polyd/. Она использует правильный путь проекта, закрыта от индексации и не содержит PHP или почтовых настроек. Формы в демонстрации показывают сообщение и не передают введённые данные и файлы.

## Рабочая отправка обращений

Для рабочего сайта необходим хостинг с PHP, OpenSSL, JSON, Fileinfo и ZipArchive. Письма и вложения формирует PHPMailer 7.2.0. Получатель: polyd-system@mail.ru.

Пример настроек: config/mail/config.example.php. На хостинге заполните public/forms/private/config.php, настройте SMTP и проверьте доставку. Не добавляйте рабочие пароли в Git. Сборка сохраняет уже существующий закрытый config.php; GitHub Pages его не публикует.

К запросу можно приложить до 3 файлов PDF, DOCX, XLSX, JPG или PNG: до 5 МБ каждый и до 10 МБ суммарно. Проверки выполняются в браузере и PHP; временные вложения удаляются после обработки.

## Исходники

- src/pages/ — страницы, поведение главной, PHP и интерактивная модель
- src/partials/ — общие шапка, футер и контакты
- src/shared/ — стили, FAQ, изображения, шрифты и локальные библиотеки
- config/ — публичные настройки и пустой пример почтовой конфигурации
- scripts/ — сборка, просмотр и проверки

Исходные изображения и оптимизированные WebP входят в репозиторий. Лицензии сторонних библиотек сохранены рядом с комплектами. public/ и .pages-dist/ создаются сборкой. Внутренние документы, архивы прежних версий, журналы, снимки проверок и рабочие настройки хранятся локально и не входят в публичную историю репозитория.
