# Структура POLYD Theatre

Авторитетный проект новой версии: эта папка. Корневая папка Polyd содержит также архивы прежних выпусков и файл открытия новой главной; они не являются исходниками этой версии.

| Путь | Назначение |
| --- | --- |
| README.md, FILE_STRUCTURE.md | Входная инструкция и карта размещения |
| package.json, .gitignore | Команды проекта и исключения |
| config/site.json | Подтверждённые сведения компании, состояние подключения отправки и юридического согласования |
| config/mail/config.example.php | Пример закрытой почтовой конфигурации без секретов |
| scripts/ | Сборка, локальный просмотр, подготовка изображений и проверки |
| src/pages/home/ | Шаблон и поведение главной |
| src/pages/faq/ | Поведение самостоятельного FAQ |
| src/pages/legal/ | Тексты документов для сборки отдельных страниц |
| src/pages/forms/ | PHP-обработчик, проверка вложений и шаблон письма |
| src/pages/process/ | Зафиксированный исходник объясняющей модели и оболочка самостоятельного просмотра |
| src/partials/ | Единственные эталонные шапка, футер и панели связи; этот обязательный путь сохранён по R-0294 |
| src/shared/ | Общие стили, поведение и тексты FAQ |
| src/shared/assets/ | Исходные изображения, промпты, варианты и оптимизированные производные |
| src/shared/vendor/provided-resources/ | Переданные ранее логотипы, исходные фото, шрифты и зафиксированные клиентские библиотеки |
| src/shared/vendor/phpmailer/ | Официальный комплект PHPMailer 7.2.0 с лицензией |
| public/ | Единственный комплект размещения; генерируется, вручную не редактируется |
| public/assets/css, js, images, fonts, files | Публикуемые ресурсы по назначению |
| public/assets/vendor/intellect/ | Самодостаточный внешний компонент; его относительная структура и лицензии сохранены |
| public/forms/request.php | Публичный почтовый обработчик |
| public/forms/private/ | Закрытые настройки, PHPMailer, проверка вложений и шаблон письма; HTTP-доступ запрещён |
| docs/ | Описание выпуска, согласований, компонентов и эксплуатационных действий |
| docs/history/ | Предыдущие инструкции и инструменты; не редактируемые исходники текущей сборки |
| audit/ | Локальные снимки требований Notion и матрица проверки проекта |
| qa/ | Результаты проверок и снимки интерфейса |
| releases/ | Сохранённые комплекты до изменения структуры |

Новый материал размещается по роли: локальная реализация у своей страницы, общий компонент в shared или обязательных partials, настройки в config, доказательства в qa, отчёт в audit либо docs. Папки под обычный одиночный файл не создаются.

Переносы от 23 ноября отражены в scripts/build.mjs и package.json. Повторная сборка читает только src и config; прежняя папка graphite-development и корневой POLYD.html больше не нужны сборке новой версии. Публичные адреса сохраняются плоскими; /demo-intellect/ отображается из demo-intellect.html. В комплекте один index.html в корне public.

Секреты вводятся только в public/forms/private/config.php на целевом окружении. Сборка не перезаписывает существующий config.php. Конфигурация возвращает массив, не печатает содержимое и дополнительно защищена Apache. Для обновления хостинга исключайте рабочий config.php из перезаписи.
